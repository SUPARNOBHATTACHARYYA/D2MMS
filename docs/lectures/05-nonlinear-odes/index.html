Lecture 05 · Geometric & Nonlinear Mechanics

Nonlinear ODEs in Mechanics: Phase Space & The Simple Pendulum

Move beyond small-angle linear approximations. Formulate conservative nonlinear equations of motion, map the global cylindrical phase portrait $(\theta, \dot{\theta})$, trace the homoclinic separatrix boundary, and evaluate exact period elongation using complete elliptic integrals.

Learning Outcomes
  • Formulate the exact non-approximated nonlinear equation $\ddot{\theta} + \omega_0^2 \sin\theta = 0$.
  • Construct the first integral of energy $E(\theta, \dot{\theta}) = \text{const}$ and trace constant-energy orbits in phase space.
  • Locate & classify center equilibrium points $(0,0)$ and inverted saddle points $(\pm\pi, 0)$.
  • Compute exact oscillation periods using complete elliptic integrals of the first kind $K(k)$.
01 · Nonlinear Dynamics

5.1 The Exact Simple Pendulum

For a point mass $m$ suspended by a rigid, massless rod of length $L$ swinging in a vertical plane under gravity $g$:

$$\ddot{\theta}(t) + \omega_0^2 \sin\theta(t) = 0, \quad \omega_0 = \sqrt{\frac{g}{L}}$$

Multiplying by $\dot{\theta}$ and integrating once with respect to time yields the Hamiltonian energy conservation law:

$$E = \frac{1}{2} m L^2 \dot{\theta}^2 + m g L (1 - \cos\theta) = \text{constant}$$

Unlike the harmonic oscillator where period $T_0 = 2\pi/\omega_0$ is completely independent of amplitude (isochronous), the nonlinear pendulum's period stretches as initial release angle $\theta_0$ increases:

$$T(\theta_0) = \frac{4}{\omega_0} K\left(\sin\frac{\theta_0}{2}\right) = T_0 \left(1 + \frac{1}{16}\theta_0^2 + \frac{11}{3072}\theta_0^4 + \dots\right)$$
02 · Geometric Topology

5.2 Cylindrical Phase Space & The Homoclinic Separatrix

The state plane $(\theta, \dot{\theta})$ is naturally $2\pi$-periodic in angle, forming a phase cylinder.

• Closed Libration Orbits ($E < 2mgL$): Concentric oval orbits around the stable downward center $(0,0)$ representing bounded back-and-forth oscillation.
• The Homoclinic Separatrix ($E = 2mgL$): Critical energy boundary connecting the unstable inverted upright equilibrium points $(\pm\pi, 0)$. A trajectory released exactly on the separatrix requires infinite time ($T \to \infty$) to reach the apex.
• Continuous Whirling Motion ($E > 2mgL$): Open, undulating phase trajectories where the pendulum has sufficient kinetic energy to spin over the top continuously.
Common Misconception · Is the Small-Angle Approximation Valid up to 45°?

Textbooks often claim $\sin\theta \approx \theta$ is acceptable for "small angles," leading engineers to apply it casually up to $45^\circ$.

At $\theta_0 = 45^\circ$ ($0.785\text{ rad}$), the period error is already $+3.9\%$. In precision clockwork or seismic sensors, this accumulates into massive phase drift over several cycles! For $\theta_0 = 90^\circ$, the exact period is $+18.0\%$ longer than $T_0$, and at $\theta_0 = 175^\circ$, the period is more than $300\%$ longer!

04 · Computational Implementation

5.4 Exact Elliptic Period & Phase Orbit Integration

Compute exact periods using complete elliptic integrals and integrate nonlinear trajectories with SciPy.

import numpy as np
from scipy.special import ellipk
from scipy.integrate import solve_ivp

g, L = 9.81, 1.0
w0 = np.sqrt(g / L)
T0 = 2 * np.pi / w0

# Exact Period vs Linear Period for theta0 = 90 deg
theta0 = np.radians(90.0)
k = np.sin(theta0 / 2)
T_exact = (4.0 / w0) * ellipk(k**2)

print(f"Linear Period T0: {T0:.4f} s")
print(f"Exact Nonlinear Period T(90 deg): {T_exact:.4f} s (Ratio: {T_exact/T0:.3f})")

# Numerical Phase Plane Integration
def pendulum_ode(t, y):
    theta, omega = y
    return [omega, -w0**2 * np.sin(theta)]

sol = solve_ivp(pendulum_ode, [0, 10], [theta0, 0.0], max_step=0.01)
