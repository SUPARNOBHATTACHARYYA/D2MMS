01 · Signal Theory

2.1 Mathematical Foundations of Discrete Fourier Analysis

In mechanical condition monitoring, continuous sensor voltages $x(t)$ (from accelerometers or strain gauges) are sampled discretely at uniform sampling rate $f_s = 1/\Delta t$.

Continuous vs. Discrete Transforms

The continuous Fourier transform maps a continuous signal $x(t)$ into continuous complex frequency spectra:

$$X(f) = \int_{-\infty}^{\infty} x(t) e^{-i 2\pi f t} \, dt, \quad x(t) = \int_{-\infty}^{\infty} X(f) e^{i 2\pi f t} \, df$$

For digital signal acquisition with $N$ discrete measurements sampled at interval $\Delta t$:

$$X[k] = \sum_{n=0}^{N-1} x[n] \exp\left(-i \frac{2\pi k n}{N}\right), \quad k = 0, 1, \dots, N-1$$
Nyquist-Shannon Sampling Criterion & Aliasing

The continuous signal frequency spectrum is unambiguously captured only up to the Nyquist folding frequency:

$$f_{\text{Nyq}} = \frac{f_s}{2} = \frac{1}{2\Delta t}$$

Any high-frequency content above $f_{\text{Nyq}}$ will fold back (alias) into the lower frequency spectrum, masquerading as spurious low-frequency vibrations! Always employ hardware analog anti-aliasing low-pass filters prior to ADC digitization.

Common Misconception · Does Zero-Padding Improve Frequency Resolution?

A widespread misconception among junior data analysts is that appending zeros to a sampled vibration vector improves the true physical frequency resolution of an FFT.

It does not. True physical frequency resolution $\Delta f$ is strictly determined by the total observation duration: $\Delta f = 1/T = 1/(N \Delta t)$. Appending zeros merely interpolates intermediate points along the continuous Fourier transform (sinc-curve interpolation) without adding a single bit of new information. To distinguish two tightly spaced mechanical modes (e.g., $100.0\text{ Hz}$ and $100.5\text{ Hz}$), you must record for a longer duration ($T \ge 2.0\text{ seconds}$).

04 · Computational Implementation

2.4 FFT Implementation in Python & MATLAB

Perform windowed FFT analysis and plot single-sided amplitude spectra.

import numpy as np
import scipy.signal as signal

# Sampling parameters
fs = 2000.0          # Sampling rate (Hz)
t = np.arange(0, 1.0, 1/fs)
N = len(t)

# Synthetic vibration signal with additive noise
x = 2.0 * np.sin(2 * np.pi * 50.0 * t) + 1.2 * np.sin(2 * np.pi * 180.0 * t)
x += 0.4 * np.random.normal(0, 1, N)

# Apply Hann window to suppress spectral leakage
window = np.hanning(N)
X_fft = np.fft.rfft(x * window)
freqs = np.fft.rfftfreq(N, 1/fs)
magnitude = np.abs(X_fft) * (2.0 / np.sum(window))

print(f"Sampling Rate: {fs} Hz | Resolution: {fs/N:.2f} Hz")
print(f"Dominant frequencies detected: {freqs[np.argsort(magnitude)[-3:]]} Hz")
% MATLAB Implementation
fs = 2000;
t = 0:1/fs:1-1/fs;
N = length(t);
x = 2.0*sin(2*pi*50*t) + 1.2*sin(2*pi*180*t) + 0.4*randn(size(t));

w = hann(N)';
X = fft(x .* w);
P2 = abs(X / sum(w));
P1 = P2(1:N/2+1);
P1(2:end-1) = 2*P1(2:end-1);
f = fs*(0:(N/2))/N;

plot(f, P1, 'LineWidth', 1.8, 'Color', [0.7, 0.38, 0.16]);
xlabel('Frequency (Hz)'); ylabel('|P_1(f)|'); grid on;
