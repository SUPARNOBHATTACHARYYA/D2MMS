Lecture 06 · Dynamical Systems & Nonlinear Stability

Phase Portraits & Stability Analysis: Invariant Manifolds & Limit Cycles

Locate equilibrium points and classify their local topology in the trace-determinant plane $(\tau, \Delta)$ of the Jacobian matrix. Map stable and unstable invariant manifolds, and explore isolated self-excited periodic orbits—limit cycles—in the Van der Pol oscillator.

Learning Outcomes
  • Linearize nonlinear planar vector fields $\dot{\mathbf{x}} = \mathbf{f}(\mathbf{x})$ around fixed points via the Jacobian matrix $\mathbf{J}$.
  • Classify equilibrium stability (saddle, stable node, stable focus, center, unstable node) using $\tau = \operatorname{tr}(\mathbf{J})$ and $\Delta = \det(\mathbf{J})$.
  • Map invariant stable and unstable manifold boundaries that partition basins of dynamic attraction.
  • Simulate limit cycles and relaxation oscillations in self-excited mechanical systems.
01 · Local Linearization

6.1 The Jacobian Matrix & Characteristic Roots

For an autonomous planar dynamical system $\dot{x}_1 = f_1(x_1, x_2)$, $\dot{x}_2 = f_2(x_1, x_2)$ with equilibrium fixed point $\mathbf{x}^*$:

$$\mathbf{J} = \left.\begin{bmatrix} \frac{\partial f_1}{\partial x_1} & \frac{\partial f_1}{\partial x_2} \\ \frac{\partial f_2}{\partial x_1} & \frac{\partial f_2}{\partial x_2} \end{bmatrix}\right|_{\mathbf{x}^*}, \quad \lambda^2 - \tau \lambda + \Delta = 0$$

Where the trace $\tau$ and determinant $\Delta$ evaluate directly to:

$$\tau = \operatorname{tr}(\mathbf{J}) = \lambda_1 + \lambda_2, \quad \Delta = \det(\mathbf{J}) = \lambda_1 \lambda_2 \quad \implies \quad \lambda_{1,2} = \frac{\tau \pm \sqrt{\tau^2 - 4\Delta}}{2}$$
02 · Geometric Topology

6.2 The Trace-Determinant Diagram

The parabola $\tau^2 - 4\Delta = 0$ partitions the $(\tau, \Delta)$ parameter plane into distinct topological regimes.

• Saddle Points ($\Delta < 0$): One positive and one negative real eigenvalue; always unstable with distinct incoming (stable) and outgoing (unstable) invariant manifolds.
• Stable Nodes ($\Delta > 0, \tau < 0, \tau^2 > 4\Delta$): Real negative eigenvalues; pure exponential decay without oscillation.
• Stable Spirals ($\Delta > 0, \tau < 0, \tau^2 < 4\Delta$): Complex conjugate eigenvalues with negative real part; decaying oscillatory trajectories.
• Center Points ($\tau = 0, \Delta > 0$): Purely imaginary eigenvalues; neutrally stable continuous concentric orbits.
• Hopf Bifurcation ($\tau$ crosses zero with $\Delta > 0$): Transition from stable focus to unstable focus with the spontaneous birth of an isolated limit cycle.
Common Misconception · Are Limit Cycles Just Linear Harmonic Oscillations?

Students often view limit cycles as simple periodic orbits identical to undamped mass-spring harmonic oscillations.

They are fundamentally different. In a linear conservative system, there are infinite continuous families of periodic orbits—perturbing the amplitude creates a new orbit. In contrast, a limit cycle is an isolated periodic trajectory in a dissipative, self-excited nonlinear system. Perturbed trajectories inside or outside the limit cycle are drawn into it asymptotically!

04 · Computational Implementation

6.4 Van der Pol Limit Cycle Integration

Simulate phase portraits and asymptotic convergence to the Van der Pol limit cycle in Python.

import numpy as np
from scipy.integrate import solve_ivp

# Van der Pol Oscillator: x'' - mu*(1 - x^2)*x' + x = 0
mu = 1.0

def vdp_system(t, state):
    x, y = state
    return [y, mu * (1.0 - x**2) * y - x]

# Integrate from interior and exterior initial states
sol_inner = solve_ivp(vdp_system, [0, 30], [0.1, 0.1], max_step=0.02)
sol_outer = solve_ivp(vdp_system, [0, 30], [3.0, 3.0], max_step=0.02)

print("Both trajectories converge asymptotically onto the unique isolated limit cycle!")
