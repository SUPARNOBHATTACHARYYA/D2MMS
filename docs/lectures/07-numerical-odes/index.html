Numerical Solution of ODEs: Runge-Kutta, Stiffness & Step Size Control

Formulate explicit and implicit time integrators via the Butcher tableau. Map complex absolute stability boundaries in the Dahlquist plane $z = \lambda h$, diagnose numerical stiffness, and implement adaptive step-size control.

Learning Outcomes
  • Derive the Butcher tableau order conditions for explicit and implicit Runge-Kutta schemes.
  • Evaluate the Dahlquist test equation $y' = \lambda y$ and calculate stability polynomials $R(z)$.
  • Diagnose numerical stiffness and identify why explicit solvers suffer catastrophic step-size bottlenecks.
  • Implement A-stable implicit integrators (Radau, BDF) and embedded adaptive step controllers (RK45).
01 · Numerical Formulations

7.1 The Classical Runge-Kutta Method (RK4)

Approximating initial value problem $y' = f(t, y)$ with step size $h = \Delta t$:

$$y_{n+1} = y_n + \frac{h}{6}(k_1 + 2k_2 + 2k_3 + k_4)$$

Where the four intermediate stage slopes are evaluated sequentially:

$$\begin{aligned} k_1 &= f(t_n, y_n) \\ k_2 &= f(t_n + \tfrac{h}{2}, y_n + \tfrac{h}{2}k_1) \\ k_3 &= f(t_n + \tfrac{h}{2}, y_n + \tfrac{h}{2}k_2) \\ k_4 &= f(t_n + h, y_n + h k_3) \end{aligned}$$
02 · Numerical Stability

7.2 Dahlquist Test Equation & Absolute Stability

Applying numerical integrators to linear scalar test problem $y' = \lambda y$ where $z = \lambda h \in \mathbb{C}$:

• Forward Euler ($y_{n+1} = (1 + z) y_n$): Stable only inside the unit disc $|1 + z| \le 1$. Requires tiny step size $h < 2/|\lambda_{\max}|$.
• Classical RK4 ($y_{n+1} = (1 + z + \frac{z^2}{2} + \frac{z^3}{6} + \frac{z^4}{24}) y_n$): Enlarged stability region on negative real axis spanning $-2.78 \le \operatorname{Re}(z) \le 0$.
• Backward Euler ($y_{n+1} = (1 - z)^{-1} y_n$): $A$-stable! Stable across the entire left complex half-plane $\operatorname{Re}(z) \le 0$, allowing unconditional stability regardless of system stiffness.
Common Misconception · Is a Stiff System Just a Fast-Oscillating System?

No. Stiffness is not merely about rapid dynamics; it is about disparity of timescales where fast transient modes decay quickly, leaving slow dynamics of physical interest.

In stiff mechanics, explicit integrators are forced to take microscopic time steps (e.g. $\Delta t < 10^{-6}\text{ s}$) solely to keep the already-decayed fast mode from exploding numerically, even when the actual solution is changing smoothly! Switching to an $A$-stable implicit solver (such as Radau or BDF) removes this stability barrier entirely.

04 · Computational Implementation

7.4 Stiff ODE Integration Benchmark

Compare explicit RK45 against implicit Radau on a stiff mechanical system.

import numpy as np
from scipy.integrate import solve_ivp

# Stiff spring-damper system: lambda1 = -1, lambda2 = -2000
def stiff_odes(t, y):
    return [-y[0], -2000.0 * (y[1] - np.sin(t))]

t_span = [0, 5.0]
y0 = [1.0, 0.0]

# Explicit RK45 (encounters step-size bottleneck)
sol_rk45 = solve_ivp(stiff_odes, t_span, y0, method='RK45')
print(f"Explicit RK45 step count: {sol_rk45.nfev} function evaluations")

# Implicit Radau (A-stable, takes large smooth steps)
sol_radau = solve_ivp(stiff_odes, t_span, y0, method='Radau')
print(f"Implicit Radau step count: {sol_radau.nfev} evaluations (Orders of magnitude faster!)")
